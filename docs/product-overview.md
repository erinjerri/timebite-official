# Product Overview

## Summary

TimeBite is being shaped into a focused learning and production system for data input.

The primary learner experience is about teaching users how to enter data into the app using:

- Speech-to-text input
- Computer vision capture
- Guided capture and review flows

The production experience is controlled by admins, who own the final build and release process.

## Intended audiences

### Learners

Learners are people who want to understand how to get data into the app quickly and reliably. The product should help them:

- Record voice input
- Capture visual input from the environment or from a device camera
- Review what was captured
- Correct or confirm the result before it is saved

### Admins

Admins manage the final production build. They are responsible for:

- Release readiness
- Configuration
- Quality control
- Final packaging and distribution

## Product principles

- Capture first, then refine
- Make input paths obvious and low-friction
- Keep learner guidance simple and progressive
- Keep admin controls explicit and separated from learner actions
- Consolidate experimental work into one stable product line

## In scope

- STT capture flow
- Computer vision capture flow
- Input review and correction
- Admin build and release workflow
- Consolidation of the experimental repos into one product direction

## Out of scope for this boilerplate

- Detailed UI components
- Backend implementation specifics
- Final data models
- Release automation details

Those can be added once the implementation is in place.
