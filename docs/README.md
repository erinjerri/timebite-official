## Documentation goals

- Keep the product scope clear
- Separate learner-facing flows from admin responsibilities
- Make the transition from the experimental repos easy to understand
- Leave room for implementation details as the codebase evolves

## Writing rule of thumb

- If the content explains the user experience, keep it in product or workflow docs
- If the content explains system structure, keep it in architecture docs
- If the content explains repo migration, keep it in consolidation docs
