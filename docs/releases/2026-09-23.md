# September 23, 2026 Apple submission reliability checklist

Release scope: Mac and Watch activity loop first; iOS and visionOS compatibility second. A check mark requires an actual target build or observed runtime behavior, not a domain-package test alone.

## Build and runtime gates

- [x] macOS target builds with Xcode 27 beta (`TimeBiteMac`, generic macOS, Debug, code signing disabled; September 15). Clean-install launch remains untested.
- [x] watchOS target builds with Xcode 27 beta (`TimeBiteWatch`, generic watchOS, Debug, code signing disabled; September 15). Launch and Mac state relay remain untested.
- [ ] Mac/Watch use the same session ID and converge after disconnect/reconnect.
- [x] iOS target builds with Xcode 27 beta (`TimeBiteiOS`, generic iOS, Debug, code signing disabled; September 15). Basic runtime loop remains untested.
- [ ] visionOS target builds and basic create/start/complete works.
- [ ] Release navigation excludes unfinished finance, admin, agent, planner, and spatial surfaces.
- [ ] No Plaid credentials, account, network, or external agent service is needed to launch or use the loop.
- [ ] Health authorization can be denied without blocking or crashing the timer.
- [ ] Health usage descriptions and entitlements match the actual read path.

## Fault cases

- [ ] Mac sleeps during running session; elapsed reconstructs from timestamps.
- [ ] View disappears and returns; no second session is created.
- [ ] Watch disconnects while running and reconnects; state and ring converge.
- [ ] Completion on either device is counted once after reconnect.
- [ ] Health access denied; activity loop continues.
- [ ] Network unavailable; activity loop continues.
- [ ] No Plaid configuration; production binary launches.
- [ ] Clean install and relaunch restore intended state.
- [ ] Day boundary allocates active time to the correct day.

## Current evidence and gaps (September 15)

The shared Swift package has automated tests for timestamp-derived elapsed time, pause/resume, completion idempotency, relaunch reconstruction, ring clamping, and day boundaries. The Mac target compiles. No application runtime or device trial has yet been completed in this destination repo. Do not mark the manual trials or other target builds as passed based on package tests.
